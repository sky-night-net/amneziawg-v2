# AmneziaWG Easy v2 🚀

Быстрая, простая и современная панель управления для **AmneziaWG 2.0**.
Проект создан как развитие популярной панели `wg-easy`, но с полной интеграцией параметров *мимикрии* (Custom Signatures) и интерактивным мастером настройки прямо в веб-интерфейсе!

## 🌟 Главные фишки
- **Мастер настройки (Setup Wizard):** Настройка сервера и установка пароля администратора при первом запуске прямо в браузере. Больше не нужно копаться в `.env` файлах!
- **Адаптивная обфускация:** Динамическое управление параметрами AWG 2.0 (`Jc, Jmin, Jmax, S1, S2, H1-H4, I1-I5`) через графический интерфейс.
- **Увравление Нодой:** Возможность менять параметры сервера и пароль администратора без перезапуска Docker-контейнера вручную.
- **Мгновенная синхронизация:** Панель автоматически применяет новые правила к WireGuard и обновляет конфиги всех клиентов.
- **Современный UI:** Темная тема, графики трафика в реальном времени и удобная выдача QR-кодов.

## 🚀 Быстрый запуск

Для запуска вам потребуются **Docker** и **Docker Compose**.

1. Клонируйте репозиторий:
```bash
git clone https://github.com/sky-night-net/amneziawg-v2.git
cd amnezia-wg-easy-v2
```

2. Запустите контейнеры:
```bash
docker-compose up -d --build
```

3. Завершите настройку:
Откройте браузер по адресу `http://ВАШ_IP:51821`. Вас встретит **Мастер настройки**, где вы сможете:
- Указать IP/домен вашего сервера.
- Выбрать порт WireGuard.
- Установить надежный пароль для входа в панель.

## ⚙️ Настройка мимикрии (AmneziaWG 2.0)

Панель поддерживает новейшие механизмы обхода блокировок (ТСПУ) через параметры мимикрии:

1. Нажмите кнопку **"AWG"** в панели управления.
2. Настройте параметры обфускации. Особое внимание уделите сигнатурам **`I1`..`I5`**:
   - `<b 0x...>` — имитация конкретных протоколов (SSH, TLS и др.).
   - `<r>` / `<rc>` — генерация случайного мусора.
3. Нажмите **"Save Settings"**. Панель сама перезагрузит интерфейс и обновит конфиги.

> [!IMPORTANT]
> После изменения настроек AWG (особенно S1/H1/I1), старые конфиги клиентов перестанут работать. Обязательно скачайте обновленный `.conf` или пересканируйте QR-код для каждого устройства.

## 🆘 Решение проблем (Troubleshooting)

- **Настройка не открывается:** Убедитесь, что порты `51821/tcp` и `51820/udp` открыты в вашем Firewall. Проверьте логи: `docker logs -f amnezia-wg-easy`.
- **Сброс настроек:** Чтобы запустить мастер настройки заново, удалите файл `wg0.json` в папке `/etc/wireguard` (или примонтированном томе) и перезапустите контейнер.
- **Ядро сервера:** Для работы AmneziaWG требуется ядро `5.6+` или поддержка расширений AWG в вашей ОС.
