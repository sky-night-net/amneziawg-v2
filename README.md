# AmneziaWG Easy v2 🚀

Быстрая, простая и современная панель управления для **AmneziaWG 2.0**.
Проект создан как развитие популярной панели `wg-easy`, но с полной интеграцией параметров *мимикрии* (Custom Signatures) и обфускации прямо в веб-интерфейсе!

## 🌟 Главные фишки
- Интегрирована поддержка **AmneziaWG 2.0 — "От камуфляжа к мимикрии"**.
- **Новое:** Динамическое управление параметрами обфускации напрямую через графический интерфейс (никакой возни в терминале и `.env`).
- Поддержка параметров: `Jc, Jmin, Jmax, S1, S2, H1-H4`, и самых свежих **`I1-I5`** (сигнатуры пакетов).
- Панель автоматически применяет новые правила к серверу и пересобирает конфиги всех пользователей.
- Выдача готовых `.conf` файлов и генерация QR-кодов.
- Интерактивные графики соединений и трафика.

## 🚀 Быстрый запуск

Для запуска вам потребуются **Docker** и **Docker Compose**.

1. Клонируйте репозиторий:
```bash
git clone https://github.com/sky-night-net/amnezia-wg-easy-v2.git
cd amnezia-wg-easy-v2
```

2. Соберите и запустите контейнеры:
```bash
docker-compose up -d --build
```
> *При первом запуске автоматически скачаются зависимости и сгенерируется дефолтный `wg0.conf`.*

3. Откройте панель управления в браузере по адресу:
`http://ВАШ_IP:51821`

*(По умолчанию веб-интерфейс открыт. Для защиты задайте переменную окружения `PASSWORD_HASH` в `docker-compose.yml`)*

## ⚙️ Настройка мимикрии (AmneziaWG 2.0)

Панель позволяет маскировать ваш VPN-трафик под легитимный трафик (например, запросы браузеров или онлайн-курсов), чтобы гарантированно пробивать любые системы ТСПУ.

1. Зайдите в панель управления.
2. В верхнем правом углу нажмите на новую кнопку **"AWG"**.
3. Откроется окно "AmneziaWG Obfuscation Settings".
4. Заполните параметры обфускации. Особое внимание уделите новым полям `I1`..`I5`:
   **Примеры синтаксиса для пакетов-сигнатур:**
   - `<b 0x2216..>` — отправка конкретных шестнадцатеричных байтов (подделка конкретного протокола).
   - `<r>`, `<rc>`, `<rd>` — случайные байты, случайные символы или случайные цифры.
   - `<t>` — UNIX таймстемп.
5. Нажмите **"Save Settings"**.
> **Панель мгновенно применит настройки, обновит конфигурации в `wg0.json`, и автоматически перезагрузит интерфейс. Все ваши клиенты сразу получат новые правила!**

## 🆘 Решение проблем (Troubleshooting)

- **Контейнер уходит в Restart Loop (бесконечный рестарт)** 
Убедитесь, что ваше ядро поддерживает WireGuard (версия ядра сервера старше `5.6` или установлен пакет `wireguard-dkms` / `amneziawg-go`). В файле `docker-compose.yml` обязательно должны быть строки `cap_add: - NET_ADMIN - SYS_MODULE`.

- **Клиенты перестали подключаться после смены настроек в AWG меню**
Обязательно скачайте новый конфигурационный файл `.conf` (или отсканируйте новый QR-код) для вашего клиента в панели *после* изменения настроек AWG! Старые клиенты с другими параметрами S1/H1+I1 не смогут установить рукопожатие с текущим сервером.

- **DPI все равно блокирует соединение**
Увеличьте значение `Jmin` и `Jmax` (сделайте мусорные пакеты длиннее, но всегда `Jmax` < MTU, чтобы избежать фрагментации). Попробуйте задать жесткие сигнатуры `I1-I5`, имитирующие известные "белые" заголовки (например HTTPS), как советуют в блоге Amnezia.
