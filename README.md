# AmneziaWG Easy Hub v2.0 🚀

Быстрая, простая и современная панель управления для **AmneziaWG 2.0** с архитектурой **Multi-Node Hub**.

Проект позволяет управлять множеством VPN-серверов из одного центрального Web-интерфейса через встроенную систему Агентов на порту **161 (SNMP style)**.

## 🌟 Основные особенности

- **Hub & Agent**: Централизованное управление парком серверов.
- **Zero-Config**: Настройка основного сервера в пару кликов через Web UI.
- **Мониторинг 24/7**: Встроенный Zabbix-style мониторинг нагрузки (CPU, RAM, Traffic) для каждой ноды.
- **AmneziaWG Obfuscation**: Полная поддержка всех параметров обфускации (Jc, Jmin, Jmax, S1, S2 и др.).
- **SNMP-Style**: Общение между Хабом и Агентами по стандартному порту **161 (TCP)**.
- **Root-Mode**: Автоматическая работа под root для управления сетевыми интерфейсами и портами.

## 🚀 Быстрый старт

### 1. Умная установка (Одна команда для всех)
Просто вставьте это в терминал **любого чистого** Linux-сервера:

```bash
curl -fsSL https://raw.githubusercontent.com/sky-night-net/amneziawg-v2/master/install.sh | bash
```

### Что сделает скрипт:
1. Проверит и установит **Docker**, если его нет.
2. Подготовит все сетевые зависимости (`curl`, `jq`, `iptables`).
3. **Интерактивно** предложит вам выбрать порты для Web UI, WireGuard и управления.
4. Развернет **Universal Node** в Docker и покажет вам **SECRET AGENT TOKEN**.

---
После завершения:
1. Зайдите в панель управления основного сервера: `http://ваш-ip-1:51821`.
2. В интерфейсе этого сервера нажмите **Add Node** и вставьте туда IP второго сервера и его токен, который выдал скрипт.

Готово! Теперь вы управляете вторым сервером из первого.

## 🛠 Управление нодами (Hub UI)

1. Зайдите в Web UI Хаба.
2. Откройте меню **Servers** в верхней панели.
3. Нажмите `+` и укажите данные удаленного агента:
   - **Name**: Название сервера (например, "Germany-1").
   - **URL**: `http://agent-ip:161`
   - **Token**: Ваш секретный ключ агента.
4. Теперь вы можете мгновенно переключаться между серверами прямо в интерфейсе!

## ⚙️ Переменные окружения

| Переменная | Описание |
| :--- | :--- |
| `AGENT_MODE` | Установите в `true`, чтобы запустить как узел (Agent). |
| `AGENT_TOKEN` | Секретный ключ для авторизации Хаба. |
| `WG_PORT` | Порт WireGuard (по умолчанию 51820). |
| `PASSWORD` | Пароль для входа в Web UI Хаба. |
